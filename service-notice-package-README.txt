料金改定のお知らせ作成ひな形　無料ファイル版 v1.0
価格と利益の計算室／2026年10月22日

【使い方】
1. ZIPを展開します。
2. notice-builder.htmlをPCのブラウザーで開きます。Excelは不要です。
3. 決定済みの新旧料金・適用日・予約済みの方の扱いなどを入力します。
4. 「文面を作る」を押し、日付・金額・条件を確認します。
5. コピー、または掲示用のテキスト保存を使います。

入力を自動保存する機能はありません。文面は手元に保存してください。
コピー操作が使えない場合は、選択した文面を端末のコピー操作で取得できます。
計算と文面作成はオフラインで動作します。紹介リンクはインターネット接続が必要です。
入力はこのHTML内で処理し、サーバーには送信しません。

【対象と制限】
サロン・1回ごとの個人レッスン向けです。
月謝制や継続契約自体の変更用文面、料金の自動決定、予約管理は対象外です。
入力は1円単位で、新料金は旧料金より高いものに限ります（上限10億円）。
予約済み・回数券等の扱いは、既存条件と照合してから入力してください。

【動作確認】
PCのChromiumによる自動検証を実施しています。
